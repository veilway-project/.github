# .github

Organisation-wide files for [veilway-project](https://github.com/veilway-project).

- `profile/README.md` is the page shown on the organisation's profile.
- `SECURITY.md` and `CODE_OF_CONDUCT.md` apply to every repository that has none of its own.
- `CONTRIBUTING.md` points to the contribution guide of the main repository.
