# Contributing

Thank you for wanting to help.

The contribution guide lives in the main repository and applies to every repository of the project: [CONTRIBUTING.md](https://github.com/veilway-project/veilway/blob/main/CONTRIBUTING.md) ([فارسی](https://github.com/veilway-project/veilway/blob/main/CONTRIBUTING.fa.md)). It explains how to report a bug, how to propose a change, the code style, and the contributor licence agreement.

Security problems are never reported in public. See [SECURITY.md](SECURITY.md).
